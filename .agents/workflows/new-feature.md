# New Feature Workflow

1. Read AGENT.md and applicable rules.
2. Identify domain and module owner.
3. Search for existing behavior and contracts.
4. Define acceptance criteria.
5. Identify tests before implementation.
6. Implement the smallest coherent change.
7. Reuse canonical logic.
8. Run targeted tests.
9. Run architecture/quality checks.
10. Run relevant integration tests.
11. Remove any temporary or duplicate code.
12. Report changed files, tests and residual risks.
