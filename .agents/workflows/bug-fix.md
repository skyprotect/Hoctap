# /bug-fix

Fix the root cause, not only the symptom.

1. Read rules/ADRs.
2. Reproduce the bug.
3. Trace root cause and impacted boundaries.
4. Add a failing regression test when practical.
5. Make the smallest safe fix.
6. Avoid duplicate fixes or new workaround layers.
7. Run targeted tests.
8. Run impacted integration/E2E tests.
9. Run relevant architecture/security gates.
10. Remove debug artifacts.
11. Re-run tests from a clean state before completion.
12. Report root cause, fix and evidence.
