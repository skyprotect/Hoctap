# Bug Fix Workflow

1. Read AGENT.md and applicable rules.
2. Reproduce the defect.
3. Locate root cause, not just symptom.
4. Add a failing regression test when practical.
5. Make the smallest safe fix.
6. Avoid adding duplicate abstractions.
7. Run targeted tests.
8. Run impacted integration tests.
9. Run architecture and quality gates.
10. Check for side effects/regressions.
11. Remove temporary debugging code.
12. Report root cause, fix and evidence.
