# /feature

Implement a feature safely.

1. Read `AGENT.md` and applicable rules/ADRs.
2. Identify domain and module owner.
3. Search for existing behavior before adding anything.
4. Define acceptance criteria and test cases.
5. Implement the smallest coherent change.
6. Avoid new abstractions unless justified.
7. Run targeted tests.
8. Run applicable architecture/quality gates.
9. Remove unnecessary or temporary code.
10. Run impacted integration tests.
11. Report files changed, tests, gates, and known risks.
