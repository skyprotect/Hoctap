# Project Quality Standards

This project follows:
- modular architecture
- explicit ownership
- low coupling / high cohesion
- automated verification
- regression protection
- secure-by-default practices
- accessibility for UI where applicable
- production release verification

Quality is assessed using multiple signals:
cohesion, coupling, complexity, testability, dependency direction, duplication, dead code, change locality and maintainability.

LOC is only an early warning signal.
